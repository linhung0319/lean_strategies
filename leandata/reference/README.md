# Reference data patches

Files here top up LEAN's bundled reference data where upstream has fallen
behind. They are version-controlled precisely because `data/` is not: that
folder is regenerated by `convert_data.py` and must not be the only home for
anything hand-maintained.

## `interest-rate-usa.csv`

Appended to `<data folder>/alternative/interest-rate/usa/interest-rate.csv`
by `leandata.lean.overlay.extend_interest_rates`, which runs as part of
`convert`. Only rows dated after the mirrored file's last entry are added, so
it is safe to run repeatedly.

**Why it is needed.** LEAN's copy stops at `2023-07-27,5.5` and upstream has
not touched the file since 2023-08-19. `InterestRateProvider.GetInterestRate`
carries the last known rate forward indefinitely
(`Lean/Common/Data/InterestRateProvider.cs:68-78`), so any backtest running
past mid-2023 silently uses 5.5% as the risk-free rate. That feeds Sharpe
Ratio, Sortino Ratio, Alpha, Treynor Ratio and Probabilistic Sharpe Ratio
(`Lean/Common/Statistics/PortfolioStatistics.cs:293-312`). Returns, drawdown
and order counts are unaffected.

**What the column means.** `PCREDIT8` is the Fed's discount window primary
credit rate. Since March 2020 it has been set at the *upper bound* of the
FOMC's federal funds target range, and LEAN's file uses the FOMC change's
effective date. Three rows already in LEAN's copy confirm both conventions:

| Row in LEAN's file | FOMC target range from that date | Upper bound |
|---|---|---|
| `2023-03-23,5` | 4.75–5.00% | 5.00 |
| `2023-05-04,5.25` | 5.00–5.25% | 5.25 |
| `2023-07-27,5.5` | 5.25–5.50% | 5.50 |

**Source.** <https://www.federalreserve.gov/monetarypolicy/openmarket.htm> —
the FOMC's own record of target rate changes. Last checked 2026-08-08; the
most recent change listed was 2025-12-11 and no 2026 changes had been
published. Cross-checked against FRED series `DPCREDIT`, which reported 3.75%
as of April 2026.

**To update**, add a row per FOMC change: effective date, then the new upper
bound of the target range.
